# Book Scene — סרטון מסצנה בספר

Pipeline ב-OpenMontage שהופך קטע מספר שהעלית לסרטון קצר, עם דמויות עקביות ונאמנות לטקסט.

## הצוות (הסוכנים)

| תפקיד | מה הוא עושה |
|---|---|
| ספרן | קורא PDF / EPUB / TXT, מחלץ טקסט עם מספרי עמודים ואת כל האיורים |
| מלהק | בונה "תנ״ך דמויות" לספר: ציטוטים מילה במילה על המראה של כל דמות, ותמונות רפרנס נעולות |
| מפיק | בוחר איתך את הקטע המדויק, אורך ועלות |
| **במאי** | כותב רשימת שוטים. כל שוט מעוגן בציטוט מדויק מהקטע, עם פרומפט לווידאו |
| מבקר נאמנות | סוכן נפרד שבודק שאין המצאות או סתירות לספר (ציון 8 ומעלה כדי לעבור) |
| **סוכן וידאו** | מייצר כל שוט ב-Kling O3 reference-to-video עם תמונות הדמויות |
| עורך | מחבר את השוטים לסרטון אחד |

## איך זה שומר על עקביות הדמויות
- לכל דמות יש תמונה קדמית ועד 3 זוויות, נעולות אחרי שאישרת אותן (`books/<book_id>/character_bible.json`).
- **אם בספר יש איור של הדמות, האיור הוא הזהות.** תמונה שתעלה בעצמך גוברת על הכל. רק כשאין תמונה בכלל, הדמות נוצרת מהתיאור בטקסט.
- בפרומפט הדמות מופיעה רק כ-`@Element1`. הפנים מגיעות מהתמונה, לא מתיאור מילולי שעלול להשתנות.
- התנ״ך שמור ברמת הספר, ולכן כל סצנה נוספת מאותו ספר משתמשת באותן דמויות.

## איך זה נשאר קרוב למקור
- כל שוט חייב ציטוט מילה במילה מהקטע. הכלי `character_bible check_shot_list` דוחה ציטוט שלא מופיע בטקסט.
- פרטים שהספר לא מציין נרשמים ב-`invented_details` ואסור שיסתרו את הטקסט.
- מבקר נאמנות נפרד עובר על כל שוט לפני שמוציאים כסף על וידאו.

## הפעלה
1. מתקינים: `pip install -r requirements.txt`, ומגדירים `FAL_KEY` (חשבון fal.ai).
2. פותחים את Claude Code בתיקיית OpenMontage ואומרים למשל:
   > "צור סרטון מהסצנה בעמודים 40–42 בספר ‎/path/to/book.pdf"
3. הסוכן יעצור לאישור שלך: בדמויות, בבחירת הקטע והעלות, ברשימת השוטים, ובשוט הראשון לפני שהוא מייצר את השאר.

## הערות
- ספר סרוק (PDF בלי שכבת טקסט) צריך OCR לפני שמתחילים.
- הטקסט והכתוביות נשארים בשפת הספר. הפרומפטים לווידאו נכתבים באנגלית, כי מודלי וידאו עובדים איתה הכי טוב.
- דיבור בעברית עם סנכרון שפתיים עדיין חלש במודלים. ברירת המחדל היא משחק בלי דיבור, עם כתוביות או קריינות.
